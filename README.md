# CalcPro — Advanced Scientific Calculator

CalcPro is a modern, feature-rich scientific calculator web application built using HTML5, CSS3, and Vanilla JavaScript. It provides advanced mathematical operations with a clean user interface, persistent calculation history, keyboard support, and customizable dark/light themes.

The project focuses on creating a smooth calculator experience while implementing modular JavaScript architecture, browser storage management, responsive design, and interactive UI features.

# Features

## Calculator Features

- Advanced scientific calculations
- Basic arithmetic operations
- Trigonometric functions
- Logarithmic calculations
- Power and square root operations
- Percentage calculations
- Expression evaluation
- Error handling for invalid calculations


## User Experience

- Clean and modern calculator interface
- Responsive design for desktop, tablet, and mobile
- Smooth animations and transitions
- Interactive button effects
- Keyboard input support
- User-friendly error messages


## Storage & Personalization

- Calculation history management
- Persistent data storage using LocalStorage
- Clear history functionality
- Dark/Light mode toggle
- Theme preference saving across sessions
